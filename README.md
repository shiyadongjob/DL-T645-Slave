# DLT645 Slave 调试工具 使用说明

## 一、概述

本工具是 **DL/T 645-2007 多功能电能表通信协议** 的本地模拟从站（Slave），用于配合主站采集软件进行开发调试。类似于 Redisant DL/T645 Slave 的功能，但完全免费开源、即开即用。

**典型应用场景：**
- 采集软件开发阶段，没有真实电表时的联调测试
- 验证主站对负功率（光伏放电）的处理逻辑
- 学习 DL/T 645-2007 协议帧结构

---

## 二、快速开始

### 2.1 环境要求

- **操作系统：** Windows 10/11（64 位）
- **.NET 运行时：** 无需安装（单文件 EXE 自包含）

### 2.2 硬件准备

需要一对 **USB 转串口线** 或 **虚拟串口对**（如 com0com），用于连接本工具和主站采集软件。

### 2.3 启动步骤

1. 双击 `DLT645_Slave.exe` 启动程序
2. 在左上角选择串口号（如 `COM3`）
3. 波特率保持默认 `9600`（DL/T 645 常用值）
4. 点击 **打开串口** 按钮
5. 启动你的主站采集软件，配置为同一个串口，即可开始通信

### 3.1 串口配置

| 控件 | 说明 |
|------|------|
| **端口** | 下拉选择本机可用 COM 口，打开后自动刷新 |
| **波特率** | 支持 1200~115200，默认 9600（DL/T 645 标准） |
| **打开/关闭串口** | 建立或断开串口监听 |
| **本机表地址** | 6 字节 BCD 地址（如 `000000000001`）。但本工具**忽略请求中的表号**，任何地址都应答 |

### 3.2 模拟行为

| 控件 | 说明 |
|------|------|
| **☑ 自动走字** | 勾选后，电表数值按设定间隔自动累加 |
| **每次走字** | 每次累加的电能值（单位 kWh） |
| **间隔** | 走字周期（单位秒） |
| **走一次** | 手动触发一次走字 |
| **☑ 光伏放电模式** | 勾选后模拟光伏逆变器向电网反向送电，产生**负的瞬时有功功率** |

### 3.3 数据表

数据表展示了协议内置的所有常用数据项。

**两种编辑方式：**
- **双击 "BCD 字符串" 列** → 直接输入内部 BCD 编码（高级用户）
- **双击 "十进制值" 列** → 输入人类可读的十进制数，工具自动转为 BCD

> ⚠️ **计算量不可编辑**：瞬时功率等由电压 × 电流 × 功率因数实时计算，双击会提示"由电压、电流、功率因数实时计算，请修改源数据"。

## 四、协议支持情况

### 4.1 已实现的控制码

| 控制码 | 功能 | 应答控制码 |
|--------|------|------------|
| `0x01` | 读数据 | `0x81` |
| `0x11` | 读数据（扩展码） | `0x91` |
| `0x02` | 读后续数据 | `0x82` |
| `0x03` | 读数据块（多 DI） | `0x83` |
| `0x04` | 写数据 | `0x84` |
| `0x13` | 读通信地址 | `0x93` |
| `0x0C` | 广播校时 | `0x8C` |

### 4.2 帧构建规则（实现细节）

- **帧头帧尾：** `0x68` + 地址域(6B) + `0x68` + 控制码(1B) + 长度域(2B) + 数据域 + `0x16`
- **CS 校验和范围：** 从第一个 `0x68` 开始，到数据域末尾（不含第二个 `0x68` 和 `0x16`）
- **数据域偏移：** 帧内数据 = 真实数据 + `0x33` 偏移量（接收时自动减回去）
- **地址匹配：** 非广播地址原样回送请求地址（等效忽略表号）；广播地址（`0x99...99` / `0xAA...AA`）回送本机地址

### 4.3 负功率编码

DL/T 645 协议用 **最高字节 D7 位** 表示符号位：

| D7 | 含义 |
|----|------|
| 0 | 正数 |
| 1 | 负数 |

本工具实现为：**数值最后一个字节的最高位 = 符号位**，与绝大多数主站兼容。

## 五、典型使用场景

### 场景 1：采集软件联调（正向用电）

1. 打开串口
2. 勾选 "自动走字"，设每次 `0.1` kWh、间隔 `5` 秒
3. 主站每 5 秒读一次电能，观察数值递增
4. 验证主站对走字的累计计算是否正确

### 场景 2：光伏放电测试（负功率）

1. 勾选 "光伏放电模式"
2. 调整 A/B/C 相电压、电流、功率因数（保持 >0）
3. 工具自动计算出**负的瞬时有功功率**
4. 主站读取瞬时功率 DI（`02030000`），验证能否正确解析负值

### 场景 3：写数据测试

1. 在主站发送 `0x04` 写命令（如修改通信地址）
2. 观察日志区收到的写入帧和工具的应答帧
3. 确认数据域偏移 `0x33` 是否正确

## 六、常见问题

### Q：主站发请求但工具没有应答？
检查以下几点：
1. 串口是否已打开（按钮显示"关闭串口"才是打开状态）
2. 波特率是否一致（推荐 9600）
3. 有没有被其他程序占用串口
4. 查看日志区是否收到请求帧（红色）

### Q：主站读不到正确的功率值？
- 确认功率因数设置正确（cosφ 在 -1.0 ~ 1.0 之间）
- 功率计算公式：`总有功 = Σ(U × I × cosφ) / 1000` kW
- 功率为计算量，需修改电压、电流、功率因数这三个源数据

### Q：负功率不显示？
- 必须勾选 "光伏放电模式"
- 且至少一相的功率因数设为**负值**（如 -0.95）
- 光伏模式下工具会自动翻转功率因数符号

### Q：能不能改小数位数？
当前版本功率固定 2 位小数。电能 4 字节 BCD × 2 位小数，电压 3 字节 × 1 位小数，电流 3 字节 × 3 位小数。如需自定义请联系开发者修改源码。

### Q：退出后数据会保存吗？
不会，当前版本数据全部在内存中，关闭程序即丢失。可在修改前截图记录，或联系开发者加 JSON 持久化功能。

## 八、二次开发

### 环境准备
```bash
pip install pyserial pyinstaller
```

### 运行源码
```bash
python dlt645_slave.py
```

### 重新打包
```bash
pyinstaller --onefile --windowed --name "DLT645_Slave" dlt645_slave.py
```

### 添加新的 DI 数据项

编辑源码 `DATA_DICT` 列表，按格式添加元组：
```python
# (DI数值, 名称, 单位, 字节数, 默认BCD, 小数位, 类型)
("02030100", "A相瞬时有功功率", "kW", 3, "000500", 2, "BCD"),
```
